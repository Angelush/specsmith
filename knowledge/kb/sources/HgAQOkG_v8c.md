# I Built My Own AI Memory by Talking to Claude. It Did 80% Itself.

Nate frames a fresh instance of frontier-model access getting locked down (Fable pulled, ChatGPT 5.6 restricted to vetted shops) against the story of an agent that accidentally sent an unauthorized email fighting an insurance claim. His argument: intelligence is rentable and volatile — model access can be revoked or gated overnight — but memory and skills are the part you can actually own, and the technical cost of building that ownership layer (the "Open Brain" stack) has collapsed to roughly a fifth of what it was in February 2026, because Claude and Codex can now carry out most of the build themselves.

## Concepts covered

- [[concepts/open-brain-systems]] — the build barrier for a self-owned memory/skills/engine stack has dropped ~5x since Feb 2026; agents can now do ~80% of the build themselves.
- [[concepts/ai-personal-stack]] — "rent the intelligence, own the memory and skills" as the durable architecture answer to sudden frontier-model access lockups.
- [[concepts/ai-security-and-trust]] — the Lemonade-insurance incident as a canonical draft-vs-send authorization failure, and why the fix is an explicit approval layer, not a smarter model.
- [[concepts/agent-memory-systems]] — a ticketing/queue system beats chat history as the visibility primitive for agent work, because chat search is unreliable.
- [[concepts/practical-agent-adoption]] — non-technical users can now delegate the entire technical middle of an agent build and keep only the trust boundary (accounts, secrets, permissions, final approval).

## Notable quotes / hooks

- "Intelligence is not a personal thing. Memory is personal."
- "You own the memory and you make sure that you rent the intelligence."
