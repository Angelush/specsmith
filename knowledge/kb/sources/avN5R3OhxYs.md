# OpenClaw Was Too Dangerous To Install. 7 Months Later Microsoft Is Bringing It To Your Company.

Microsoft Autopilot (formerly Scout) takes OpenClaw's open-source agent setup, gives it an identity IT can audit, and sells it through 450M+ Microsoft 365 commercial seats, so for many workers it will be the agent their employer allows. Nate finds it not especially intelligent; the value is data access plus user skill, producing a K-shaped split where ~5% of employees get compounding value. His five takeaways work with any AI: define what good looks like on a real assignment, supply the right sources and check the evidence, make a working assignment recur with explicit limits, match reasoning to difficulty (the auto-router problem), and improve the next run by diagnosing and saving fixes. He also notes the counter-case for labs: a capable enough model may redesign the process rather than automate it, and Meta is entering the enterprise contest.
