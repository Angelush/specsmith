# Should You Pay $100 A Month For OpenAI's Dots When Meta's Muse Has A Free Version?

A Dev Day recap. OpenAI launched Dots (always-on agents with a cloud computer, memory and background work, from the $100 Pro tier), Spaces/Pages (shared human+agent workspaces), GPT 6.1 Soul (near-Astra on selected evals at about a fifth of the token price), Codex cloud environments, a Decisions API for constrained classification, plugin extensions and "log in with ChatGPT". Nate's thesis: agent form factors are converging (computer + memory + background work), but utility is not. Agents win on the specific recurring jobs they do well. He covers how Dots handles context salience and memory boundaries, why shared workspaces need decision rationale and not only the latest document, his current model allocation, and why every paid AI plan should be treated as an investment that has to pay itself back.

## Concepts covered

- [[concepts/practical-agent-adoption]] — form factor converges, utility does not; anchor a new agent on one recurring work responsibility.
- [[concepts/agent-memory-systems]] — proactive agents over-weight recent context; opt-in memory boundaries make disclosure a deliberate choice.
- [[concepts/model-selection-frameworks]] — move bulk work to the cheap near-frontier tier and keep the frontier model for jobs that need it.
- [[concepts/ai-roi-and-value-proposition]] — faster, pricier tiers put a premium on steering skill; have a plan to make the subscription back.
- [[concepts/organizational-ai-transformation]] — shared AI workspaces need decision rationale brought in from private chats, not only the latest doc.
- [[concepts/general-purpose-classifiers]] — constrained-choice decision APIs make classification-shaped business problems cheap to automate.

## Notable quotes

- "Form factor for agents is converging... Utility in my mind is not converging."
- "Do you know how fast you can get a wrong answer at a pricey price with that?"
