# The end of the app era: What comes next?

Starting from DoorDash's text-ordering agent and MCP beta, Nate argues that single-purpose SaaS gets easier to leave as agents take over information processing, while the agent a person has trained (skills, memory, harness) becomes the sticky asset and a hidden switching cost when leadership changes AI vendors. He surveys Meta Muse for small business, Salesforce (data layer + agent gateway + its own CRM model), Microsoft Autopilot, the labs, and small data providers like Crust Data, and proposes a three-layer lens for builders, buyers and employees: data layer, application (structured workflow) layer, and agentic layer.

## Concepts covered

- [[concepts/ai-personal-stack]] — the agent you train accumulates undocumented tribal knowledge; keep it portable and share how you work, or a vendor switch costs weeks.
- [[concepts/practical-agent-adoption]] — buy the structured data, build a skill over its API; keep high-compliance workflows (payroll) on vendor rails.
- [[concepts/mcp-architecture]] — being reachable via MCP is table stakes; it gets you considered, not retained.
- [[concepts/enterprise-ai-adoption]] — map the team's "fingerprint" AI usage before consolidating vendors; analyze stacks as data, application and agentic layers.

## Notable quotes

- "Being reachable by an agent in 2026 and 2027 is going to get you considered in the conversation. It is table stakes."
- "Applications have to be decomposed into interfaces and workflows."
- "Everyone is now a decision maker."
