# Codex Tutorial: Build Your First AI Agent Delegation Loop

Nate argues Codex is not only a developer tool: with computer use, plugins and goals it lets knowledge workers hand whole jobs to an agent that works across files, browser and documents. He describes a "chief of staff" thread that stays pointed at the work, threads that own jobs while sub agents handle contained pieces, turning repeated corrections into skills, a custom live "heads-up display" dashboard built from your own sources, and a five-part loop for a first delegation (goal, sources, standard, permission boundary, proof of done), with safety habits (no secrets in chat, read before write access, receipts).
