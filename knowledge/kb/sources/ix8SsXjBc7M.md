# There Are Jobs You Could Never Give AI. I Gave GPT-6 Astra 20 Hours Of Admin.

Nate tests GPT-6 "Astra" on a household move (20+ hours of admin) and calls it the "Claude Code moment for knowledge work": hand the model a whole outcome that spans sites, docs and calendars instead of prompting piece by piece. The skill that matters is agent supervision via a "manager loop" (one manager agent interviews you, spawns execution agents, keeps unblocked work moving, returns only decisions), and a post-prompt artifact he calls a "recipe card" that names the job, sub-jobs, questions to ask, what the agent handles, when it returns, and which actions need approval. Humans keep irreversible choices, risk and responsibility.

- [[concepts/knowledge-work-delegation]] — delegate whole outcomes, not tasks; recipe cards as the post-prompt delegation form; the decisions that stay human.
