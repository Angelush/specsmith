# Agents Aren't Taking Your Jobs. They're Creating More Work Instead.

**Video:** [https://www.youtube.com/watch?v=IpEaSa7tgfc](https://www.youtube.com/watch?v=IpEaSa7tgfc) • **ID:** `IpEaSa7tgfc` • **Playlists:** P2

## Concepts covered

- [[concepts/ai-job-market-dynamics]] — Agents create more human work (Jevons effect); the human job moves "above the loop" into agent allocation and management.
- [[concepts/knowledge-work-delegation]] — Humans make ~70% of planning decisions, agents nearly all execution; experts steer better than novices.
- [[concepts/practical-agent-adoption]] — Start with work you already do and let the agent do the preparatory step; verifiable domains (legal, coding) adopt fastest.
- [[concepts/enterprise-ai-adoption]] — Enterprises out-return SMBs because of the work done around the agent (FDE teams, controls, integration), not the model.
- [[concepts/ai-security-and-trust]] — PocketOS: an agent with an account-wide token deleted production in 9 seconds; scope permissions and plan recovery.

## Notable quotes / hooks
