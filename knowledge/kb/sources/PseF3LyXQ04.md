# Two Ways To Use Reverse Engineer Anything. One Of Them Works Even If You Can't Code.

Nate walks through "Reverse Engineer Anything" (REA), an open-source tool that plugs into Claude Code or Codex and lets an agent open up software on your machine and show how it is built. His thesis: it is an accelerator for developers and an "x-ray machine" for non-developers, and the real value is requirements discovery. Case studies (Notion clipboard, Windows calculator percent button, QuickBooks to "Ledger Reborn", Chromium dino game) show that seeing a working implementation exposes the behaviors a vague request like "make copy-paste work" never specifies. He closes with practical guidance: tell the agent how deep to go, use it to learn, and remember it only sees client-side code.

## Concepts covered

- [[concepts/prompting-and-skill-design]] — a feature name is a teaser trailer; real specs name the context-dependent behaviors, and investigation depth must be scoped.
- [[concepts/vibe-coding-phenomenon]] — requirements are often discovered by observing a working system, not fully known up front.
- [[concepts/ai-assisted-research]] — use an agent as a tireless teacher on real implementations; explain it back in your own words.

## Notable quotes

- "You cannot always finish figuring out what you want, and then hand the completed requirements to somebody else, because sometimes you're discovering it as you go."
- "Tell your microscope what to focus on."
- "Engineering work is becoming less 'can I understand the system' and more 'deciding how I want to configure the system.'"
