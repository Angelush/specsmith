# You Can't Run AI Agents Without This

**Video:** [https://www.youtube.com/watch?v=rh_PcL26zls](https://www.youtube.com/watch?v=rh_PcL26zls) • **ID:** `rh_PcL26zls` • **Playlists:** P3

## Concepts covered

- [[concepts/agent-harness-and-maintenance]] — every agent that reads real context and produces work others act on needs a single owner; care-and-feeding means giving it a job, a diet, boundaries, and a review loop, plus an "owner card" / agent roster so humans can see what each agent does.
- [[concepts/practical-agent-adoption]] — the three eras of AI skill: prompting (2023), delegation (2025), and maintenance (2026); credit should go to owning an agent that delivers value, not to building more agents.

## Notable quotes / hooks

- "The fastest way to make an AI agent dangerous is to let everyone use it and nobody own it."
- "Give it a job. Give it a diet. Give it boundaries. And give it a review loop."
- "Just building a new agent, you shouldn't get credit for these days."
- "They're your pets. You know what work you delegated and what responsibility you kept."
