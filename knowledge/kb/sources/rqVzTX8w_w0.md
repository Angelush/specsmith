# My AI Workflow Has Changed (Here is What I Learned)

**Video:** [https://www.youtube.com/watch?v=rqVzTX8w_w0](https://www.youtube.com/watch?v=rqVzTX8w_w0) • **ID:** `rqVzTX8w_w0` • **Playlists:** P0

A short weekly "how I'm using AI this week" update from Nate. Two changes stand out: a Codex-specific workflow for assembling clean local-folder context windows from natural-language file descriptions, and a broader shift in prompting style from "task + done-criteria" to collaborative "define the shape together, then execute."

## Concepts covered

- [[concepts/ai-productivity-workflows]] — Codex-driven local-folder context assembly lets Nate hand off 30-50k word document, spreadsheet, and coding tasks by having Codex locate and copy relevant files by natural-language description into a clean working folder.
- [[concepts/prompting-and-skill-design]] — Since the 4.7/5.5 model refresh, Nate's prompting has shifted from "here's your task and here's how you'll know it's done" to a two-phase collaborative flow: first define the shape of the task together, then execute agentically.
