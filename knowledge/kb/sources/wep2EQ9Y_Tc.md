# Google Has More Data Than Almost Anyone. So Why Is It Bidding $10 Million On Old Emails?

Nate uses Google's $10M bid for bankrupt Spirit Airlines' email and Teams archives to ask what knowledge work actually is. Work archives record the performance of work (follow-ups, status pings, meetings) next to the rare decisive intervention, and an agent trained on them cannot tell the difference; a closed ticket can look like success while a duplicate payment surfaces weeks later. Whoever writes the training assignments and success checks is defining "done" for your role. He argues agent value lies in repeatable drudgery run as data-in/format-out pipelines with no conversational medium, and that the best agent-human collaboration he has seen starts with boring, well-structured markdown records of truth that feed product docs and evals.

## Concepts covered

- [[concepts/agent-evaluation-and-reliability]] — trace-based success signals (ticket closed, thread approved) mislead; whoever writes the success check defines the job, so write what a correct result depends on.
- [[concepts/knowledge-work-delegation]] — delegate the repeatable drudgery as a data-to-format pipeline, not the performance of work (Slack, standups, follow-ups).
- [[concepts/open-brain-systems]] — curated markdown records of truth beat querying messy, partial Slack/email archives as agent context.
- [[concepts/enterprise-ai-adoption]] — rollouts framed as replacement trigger quiet sabotage; tie AI use to how a person drives revenue or cuts cost.
