# I Was The Only Thing Connecting Claude, ChatGPT, and Codex. So I Built My Replacement.

**Video:** [https://www.youtube.com/watch?v=QSK4vf_ZTRA](https://www.youtube.com/watch?v=QSK4vf_ZTRA) • **ID:** `QSK4vf_ZTRA` • **Playlists:** P0

## Concepts covered

- [[concepts/open-brain-systems]] — launches "Open Engine": after Open Brain (memory) and Open Skills (procedure), the third piece is how work *moves* between agents, via a shared queue rather than a human acting as the hallway between tools.
- [[concepts/issue-tracking-evolution]] — put work in a queue (Linear/Jira/Kanban) that both people and agents can read; the ticket—not the chat box or Slack—becomes the system of record and the place where agents from different providers coordinate via claims, receipts, and statuses.

## Notable quotes / hooks

- "If every loop lives in its own room, the human becomes the hallway."
- "A prompt asks for an answer. A ticket asks for a result to get done."
- "A chat box is a terrible way to manage state. And I'm sorry, but so is Slack."
- "Output is what the AI returns right now. Work is what someone can review, accept, and build on."
