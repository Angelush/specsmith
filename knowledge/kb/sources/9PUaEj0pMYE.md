# The Skill vs Prompt Problem Everyone Gets Wrong

**Video:** [https://www.youtube.com/watch?v=9PUaEj0pMYE](https://www.youtube.com/watch?v=9PUaEj0pMYE) • **ID:** `9PUaEj0pMYE` • **Playlists:** P0, P2

## Concepts covered

- [[concepts/open-brain-systems]] — launches "Open Skills": a portable library of reusable agent *procedures* (the operating layer above Open Brain's memory layer), with skills as primitives and runbooks as compositions.
- [[concepts/prompting-and-skill-design]] — a prompt is something you say once; a skill is a reusable procedure (trigger rules, scope, tools, output, verification) the agent knows from now on.

## Notable quotes / hooks

- "A prompt is something you say once. A skill is something your agent knows how to do from now on."
- "Don't put every rule in the agent's head all the time. Give it a clean way to load the right procedure when the work calls for it."
- "If open skills becomes just another list of useful prompts, I failed."
