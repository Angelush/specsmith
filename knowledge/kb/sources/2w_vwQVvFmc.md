# The Doing Got Cheap. Now What? | Claude Fable 5 Changes Work

Nate reviews Claude Fable 5, a very large new pre-train, and argues the binding constraint is now the size of what we ask for, not model ability. Prompt-sized asks make every frontier model feel the same. He proposes a skill he calls task imagination (give a job, not a prompt), a concrete recipe (find the gnarly unowned work, assemble a data pack, write a paragraph defining done, walk away, review like an owner), and notes the real misses: cost, visual taste, handwritten-image blind spots, and a review step that still lands on the human.

## Concepts covered

- [[concepts/knowledge-work-delegation]] — task imagination: unowned, dirty, ambiguous jobs; data pack plus definition of done plus review trail.
- [[concepts/model-comparison-and-performance]] — big-model behavior (quarantine instead of silently fixing, self-built review queue) and its honest limits.

## Notable quotes

- "The limit I kept hitting was not the model running out of ability. It was me running out of big things to ask for."
- "Ask suggests a prompt. Give is going to produce a job."
- "It behaved like it expected to be checked."
