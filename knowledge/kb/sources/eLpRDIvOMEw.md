# You can be ambitious without the huge token bill. Here's how.

From Dreamforce (Q&A with Marc Benioff plus a panel with Salesforce, PwC and Pepsi). Nate argues agent token costs multiply (more runs times far more tokens per run) and that the first lever is deleting work, not buying a cheaper model: redraw each value stream from the desired business result ("blank sheet"), strip handoffs that existed only because systems could not share information ("interoffice envelope with agents"), then route the remaining work by difficulty (deterministic tools, cheap/open-weight models with thick harnesses, frontier model with a thin harness for exceptions), and verify with evals. Also: put agents where people already work (Slack) to drive adoption.

## Concepts covered

- [[concepts/ai-roi-and-value-proposition]] — cost multiplies via runs x tokens-per-run; remove work first; judge spend by value, not the token leaderboard.
- [[concepts/model-selection-frameworks]] — classifier routing: ordinary work to cheaper/open-weight models, edge cases to frontier; "which model can do this job well" replaces "which model wins everything."
- [[concepts/agent-harness-and-maintenance]] — thick harness for weaker models at scale, thin harness for frontier models on exceptions.
- [[concepts/agent-evaluation-and-reliability]] — evals as the check that a redesigned process and a cheaper model still work; evals as a teachable human skill.
